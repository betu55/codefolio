# Codefolio

Codefolio is a full-stack personal portfolio platform built with **React**, **Spring Boot**, and **PostgreSQL**. It showcases projects, experience, technical work, and job tracking data, with authenticated admin CRUD features for managing content.

## Tech Stack

### Frontend
- React
- JavaScript
- Tailwind CSS

### Backend
- Java
- Spring Boot
- PostgreSQL
- REST APIs
- JWT Authentication
- Maven

## Features

- Responsive portfolio interface
- Projects and experience sections
- Job tracker support
- Admin login
- Authenticated CRUD operations
- Add, edit, delete, and reorder content
- PostgreSQL database persistence
- REST API communication between frontend and backend
